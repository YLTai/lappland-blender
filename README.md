# 原版五星拉普兰德双剑 · 参数化 Cosplay 模型

当前版本依据部件几何重建，不再把透视图的边缘描线当作三维轮廓。范围只含原版 / E2 / 幼狼的牙齿；不含典雅噩兆与荒芜拉普兰德。

## 核心几何

护手由外半径 175 mm、内半径 150 mm 的同心半圆环、直径梁、同心凸缘与上肩凹槽组成。每片严格为 180°。直径梁只占自身半平面；第二片以刚体变换移到对侧，两片真实护手网格组成直径 350 mm 的圆，而不是用两个独立描出的不规则曲线凑圆。

剑身由参数化弯曲规律、宽剑根、窄主剑身和圆钝鼻端组成。握柄为浅色椭圆主体、深色交叉接缝与深色端帽。`semantic_geometry.py` 实现部件规则，`model.py` 保存尺寸，`lappland_geometry.py` 复用本次任务中自写的基础网格/导出工具。活动模型不再调用像素描线函数。

## 生成与文件

运行现有 Blender Build Actions，或使用 Blender 4.2.1：

```sh
blender -b --python model.py
blender -b --python render.py
```

`lappland-build` 包含可编辑 `lappland_original_pair.blend`、带材质双剑 GLB、毫米单位 A/B 单剑 STL 与双剑 STL、17 张 PNG、参数与验证 JSON，以及源码。新增 `lappland_guard_circle_proof.glb`。BLEND 含两个场景：原版双剑、真实护手配圆验证。后者只检查护手框的几何配对，不宣称两把整剑可无碰撞锁合。

PNG 覆盖正面、背面、侧面、顶面、45°、护手、刀尖、握柄、无材质轮廓，以及配圆正面、配圆 45° 和接缝局部。模型与 PNG 的哈希在 SHA256SUMS.txt。

## 尺寸、来源与安全

等身尺度为约 1.08 m 总长、210 mm 柄段；并非官方标注尺寸。主剑身宽 31.5 mm / 厚 8.5 mm，宽剑根约 50 mm / 名义厚 11.5 mm。护手芯体厚 12 mm，周边层厚 17.2 mm，上肩层厚 24.4 mm。背面、具体厚度与小连接件属于参考支持下的推断。

STL 使用毫米，Blender/GLB 坐标使用米。保持 3.2 mm 名义钝边与 4 mm 名义圆鼻，用于轻软 Cosplay 道具参考；不制作真实刀刃，不构成抗冲击安全认证。整剑 STL 不是打印机专用分段套件。
